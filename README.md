## What it does

- live dashboards with history
- energy monitoring
- device sensors with rules and alerts
- a security panel with a kill switch and a live event stream
- encrypted backups
- an offline queue that survives disconnects
- a local AI assistant that reads only your own data
- multi-user roles

Also included, and I will not pretend otherwise: shop and POS modules with Thai PromptPay QR and Thai VAT 7%. Outside Thailand, ignore those modules.

## Why a one-time license

The app verifies a signed license locally with Ed25519, so there is no server to phone home and nothing I can switch off later. Machine-bound, one free transfer per year. The trade-off is honest: a signed token cannot be revoked instantly online, so I sell perpetual and one-year licenses with a published key fingerprint instead of pretending revocation works.

The project is open-core, so the claim is checkable: read what would run on your machine, verify a release against the fingerprint, then decide whether to buy.
